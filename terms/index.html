서비스와 적용 범위

DBG Desk는 사용자 PC의 GDB에 연결하는 디버깅 화면과 개발 학습 콘텐츠를 제공합니다. 현재는 로컬 개발 버전으로 제공되며 회원 가입, 유료 결제, 원격 실행 서비스는 없습니다. 이 안내의 시행일은 2026년 10월 17일입니다.

디버깅 대상과 실행

사용자는 조사 권한이 있는 실행 파일과 프로세스를 대상으로 기능을 사용해야 합니다. 실행, 계속, 단계 실행은 대상 코드를 실제로 진행하며 대상 프로그램의 파일 기록, 네트워크 통신 등 동작을 발생시킬 수 있습니다. 디버거를 정지하거나 종료했다고 이미 수행한 작업이 되돌아가지는 않습니다. 중요한 데이터에 영향을 줄 수 있는 프로그램은 재현용 입력과 별도 테스트 환경에서 확인하는 것이 좋습니다.

기능 범위와 호환성

현재 제공 범위는 GDB 연결, 파일 실행, PID 연결, 기본 중단점, 명령어 실행 제어, 상태 조회 및 정지 중 메모리·레지스터 수정입니다. 운영체제 권한, GDB 버전, 아키텍처, 실행 파일과 심볼 형식에 따라 일부 기능을 사용할 수 없습니다. Windows CI에서 C 예제의 실제 GDB 동작을 검증했으나 모든 프로그램의 정상 연결이나 디버깅 결과의 완전성을 보장하지 않습니다. 화면에 표시한 한 시점의 값만으로 원인을 확정하지 말고 재현 자료와 빌드 조건을 함께 확인해야 합니다.

콘텐츠 이용

가이드는 학습과 문제 조사에 도움을 주기 위해 작성한 설명입니다. 예제는 자신의 환경에서 실행 조건과 결과를 확인해 사용하세요. 외부 문서와 도구의 이름은 참고를 위한 것이며 해당 프로젝트와의 제휴를 뜻하지 않습니다. OllyDbg, GDB 및 관련 제품의 명칭과 권리는 각 권리자에게 있습니다. 가이드 전문을 출처 없이 재게시하거나 제3자의 비공개 자료를 문의에 첨부하지 마세요.

변경과 문의

개발 과정에서 기능과 안내가 바뀔 수 있습니다. 변경 내용은 프로젝트 안내와 관련 페이지에 반영합니다. 문의는 psiwoo66@gmail.com으로 보내주세요. 문의 양식은 메일 작성 창을 여는 기능이며 최종 전송은 사용자의 메일 앱에서 이루어집니다. 이 안내는 적용 법령상 인정되는 권리를 배제하려는 취지가 아닙니다.
