DBG Desk

파일을 열고, 한 명령씩 실행하고, 값이 바뀌는 곳을 찾는 디버거입니다. 브라우저에서 바로 쓰거나 PC의 GDB에 연결해서 쓸 수 있습니다. OllyDbg나 GDB의 공식 서비스는 아닙니다.

브라우저에서 바로 실행

ELF·PE의 x86/x64 명령어를 실행합니다. 주소를 눌러 중단점을 걸고, 레지스터와 메모리를 보거나 수정할 수 있습니다. ELF·PE 예제는 32비트와 64비트가 각각 들어 있습니다. 마지막 작업은 이 브라우저에 저장해 두고 다시 열 수 있습니다.

Linux 입력·출력은 read·write·exit 등 일부 호출만 됩니다. Linux 동적 로더·공유 라이브러리나 Windows DLL·API가 필요한 프로그램은 멈출 수 있습니다.

PC의 GDB에 연결

실행 중인 프로세스에 붙거나 소스 줄, 호출 스택, 지역 변수를 보려면 로컬 GDB 모드를 쓰세요. Python과 GDB를 설치한 뒤 로컬 서버를 실행하면 됩니다. 조건부 중단점, 데이터 중단점, 스레드 선택도 여기서 사용할 수 있습니다.

Linux에서는 웹 입력 패널을, Windows에서는 별도 콘솔을 씁니다. 프로그램과 운영체제, 디버그 심볼에 따라 볼 수 있는 정보가 달라집니다.

기록과 비교

로컬 GDB 모드는 최근 정지 상태를 모아 두고 레지스터와 메모리 값의 차이를 보여줍니다. 기록은 Markdown으로, 경로·인수·기본 중단점은 작업공간 JSON으로 저장할 수 있습니다. 메모리에서 문자열이나 HEX 패턴을 찾고 바이트를 정수·실수로 읽는 도구도 있습니다.

정지 기록은 이전 값을 보는 기능입니다. 프로그램을 과거 시점으로 되돌려 실행하지는 않습니다.

가이드

GDB 설치, 중단점, 메모리 오류와 Python·JavaScript 오류를 다룹니다. 각 글 아래에 참고 문서를 붙였습니다. 잘못된 설명을 찾으면 문의 페이지에 글 주소와 수정할 내용을 남겨 주세요.

파일과 문의

선택한 파일과 디버깅 데이터는 서버로 보내지 않습니다. 브라우저 모드는 이 기기에서, 로컬 GDB는 PC의 프로세스에서 실행합니다. 소스는 ZIP으로 내려받을 수 있습니다. 문의는 공개 GitHub 이슈로 받습니다. 현재 광고는 없습니다.
