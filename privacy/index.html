애드센스 사이트 확인

사이트 심사를 위해 Google AdSense 게시자 확인용 메타 태그와 ads.txt 판매자 승인 정보를 게시했습니다. 이 정보 자체는 광고 스크립트를 실행하거나 광고 쿠키를 생성하지 않습니다. 현재 광고는 게재하지 않으며, 광고 코드를 도입하기 전에 개인정보처리방침과 필요한 동의 설정을 갱신합니다.

공개 웹사이트

이 사이트는 브라우저 CPU 디버거, 가이드와 소스 다운로드를 제공합니다. 파일 업로드나 원격 디버깅 API는 공개하지 않습니다. DBG Desk가 추가한 광고·분석 코드는 없습니다. 이 사이트는 GitHub Pages에서 제공합니다. GitHub는 로그인 여부와 관계없이 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요. 운영 및 문의 창구는 DBG Desk의 문의 페이지입니다. 문의는 공개 GitHub 이슈로 받으므로 개인정보를 적지 마세요. 아래 항목에서 브라우저 모드와 로컬 GDB의 처리 방식을 구분해 설명합니다.

적용 범위

이 안내는 DBG Desk 공개 웹사이트, 브라우저 CPU 모드와 내려받아 사용하는 로컬 GDB 디버거에 적용됩니다. 브라우저 모드는 이 탭의 워커에서 기계어를 실행하고, 고급 로컬 GDB 모드는 사용자 PC의 127.0.0.1 Python 서버를 이용합니다. 공개 호스트에서 사용자의 바이너리를 실행하지 않습니다. 최초 시행일은 2026년 10월 17일이며 2026년 10월 18일 수정했습니다.

로컬 GDB · 디버깅 과정에서 처리하는 정보

실행 파일 경로, 프로그램 인수, PID, 중단점, 레지스터, 메모리 일부, 호출 스택과 디버거 출력은 기능 제공을 위해 브라우저와 로컬 서버 사이에서 처리됩니다. 이 정보는 연결한 GDB 및 대상 프로세스의 상태를 바탕으로 생성됩니다. 메모리와 출력에는 프로그램이 다루는 개인정보나 비밀 값이 포함될 수 있으므로 화면과 로그를 공유하기 전에 내용을 확인해야 합니다.

현재 구현은 디버깅 데이터를 외부 서버로 업로드하지 않습니다. 디버거 이벤트는 로컬 서버 메모리에 최근 항목을 보관하며 별도 데이터베이스나 로그 파일에 저장하지 않습니다. 서버 종료 후 해당 메모리 상태는 유지되지 않습니다. 다만 대상 프로그램이 스스로 기록하는 파일과 운영체제·브라우저의 기록은 이 도구가 관리하는 정보와 구분됩니다.

로컬 GDB · 선택한 바이너리 파일

파일 선택 창이나 드래그 앤 드롭으로 연 파일은 같은 PC의 로컬 서버로 전달하고 운영체제 임시 폴더에 복사합니다. 외부 서버에는 보내지 않습니다. 파일별 최대 크기는 128 MiB이며 한 서버 세션에서 최대 32개, 합계 512 MiB까지 보관합니다. 원본 파일은 변경하지 않습니다. 임시 복사본은 서버를 정상 종료할 때 삭제하며, 강제 종료나 시스템 오류가 발생하면 임시 폴더에 남을 수 있습니다. 경로 입력으로 여는 파일은 이 복사 과정을 거치지 않습니다.

로컬 GDB · 브라우저 저장소와 인증

로컬 API 접근을 위한 임시 인증값을 해당 탭의 sessionStorage에 저장합니다. 서버를 시작할 때 새 인증값을 생성하며, 인증 URL을 처음 읽은 뒤 주소창에서 인증 부분을 제거합니다. 탭을 닫으면 일반적으로 해당 탭의 세션 저장소가 종료되지만 브라우저의 세션 복원 방식에 따라 보관 상태가 달라질 수 있습니다. 브라우저 개발자 도구에서 세션 저장소를 지워 직접 삭제할 수도 있습니다. 이 버전은 추적 쿠키, 외부 분석 스크립트와 광고 스크립트를 사용하지 않습니다.

문의 내용

문의 양식은 입력한 제목과 내용을 GitHub 이슈 작성 화면에 전달합니다. 자동으로 등록하지 않습니다. GitHub 계정이 필요하며 사용자가 등록하면 내용은 공개됩니다. GitHub 사용자 이름과 등록한 정보는 GitHub의 개인정보처리방침에 따라 처리됩니다. DBG Desk는 이 양식에서 이메일 주소를 수집하지 않습니다.

문제를 설명하는 데 필요한 내용만 적어주세요. 개인정보, 인증 URL, 비밀번호나 비공개 메모리 덤프를 등록하지 마세요. 본인이 등록한 이슈 내용은 GitHub에서 수정하거나 삭제할 수 있습니다. 정보 삭제를 요청할 때도 공개 이슈에 해당 개인정보를 다시 적지 마세요.

외부 링크와 향후 광고

공식 문서나 GitHub 링크를 열면 해당 외부 서비스의 개인정보처리방침이 적용됩니다. 공개 웹사이트에는 애드센스 확인용 메타 태그와 ads.txt가 있으나 현재 DBG Desk가 추가한 광고·분석 스크립트는 실행하지 않습니다. 광고 코드를 도입하기 전에 실제 데이터 처리와 필요한 동의 설정을 안내하겠습니다. 웹사이트는 첫 방문 다운로드 팝업을 표시하거나 새 다운로드 선택 설정을 저장하지 않습니다.

운영 정보와 요청 경로

운영 명칭은 DBG Desk입니다. 오류 제보, 문서 수정 및 데이터 처리 관련 문의는 문의 페이지를 이용하세요. GitHub 공개 이슈의 작성 화면을 열며 사용자가 GitHub에서 등록하기 전에는 게시하지 않습니다. 공개 문의에 개인정보를 적지 마세요.

로컬 GDB · 정지 기록과 내보내기

정지 상태 비교를 위한 최근 50개 기록은 현재 페이지의 메모리에만 보관합니다. 새로고침하거나 다른 페이지·언어로 이동하면 지워집니다. 자동으로 외부 전송하거나 브라우저 영구 저장소에 쓰지 않습니다. 보고서를 저장하면 선택한 기록의 레지스터와 명령어·호출 스택이 사용자 PC의 Markdown 파일에 포함됩니다. 메모리 바이트와 출력 로그는 옵션을 선택한 경우에만 포함합니다. 작업공간 JSON에는 실행 파일 경로, 인수와 중단점이 포함되며 인증 토큰이나 바이너리 파일은 넣지 않습니다. 내려받은 파일은 사용자가 직접 보관·삭제하고 공유 전에 내용을 확인해야 합니다.

로컬 GDB · 스레드와 프레임 조회

스레드 목록과 선택한 호출 프레임의 지역 변수는 다른 디버깅 값과 마찬가지로 브라우저와 같은 PC의 로컬 서버에서 처리합니다. 자동 외부 전송이나 별도 영구 저장은 하지 않습니다. 정지 보고서에는 스레드·프레임 번호를 포함하지만 지역 변수 표 전체를 자동으로 넣지는 않습니다.

브라우저 CPU 모드

브라우저 모드에서 선택하거나 놓은 파일은 이 탭에서 읽어 Web Worker로 전달합니다. 파일 바이트, 에뮬레이션 레지스터·메모리, 중단점과 입력·출력은 서버로 업로드하지 않습니다. 브라우저 메모리에 보관하며 새로고침하거나 탭을 닫으면 사라집니다. 사이트는 같은 호스트에서 고정 버전의 엔진 파일과 실습 예제를 내려받습니다. 외부 런타임 CDN을 호출하거나 선택한 바이너리를 브라우저 영구 저장소에 보관하지 않습니다.
