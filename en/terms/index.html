Service and scope

DBG Desk provides a browser interface for GDB on your computer and development learning material. It is currently a local development version without membership, payments, or a remote execution service. These terms take effect on October 17, 2026.

Targets and execution

Use the debugger only with executables and processes you are authorized to inspect. Run, Continue, and stepping actually execute target code and can cause file writes, network requests, or other effects. Pausing or closing the debugger does not undo completed operations. Programs that affect important data should be investigated with reproduction inputs in an appropriate test environment.

Features and compatibility

Current features include GDB connection, executable opening, PID attachment, basic breakpoints, instruction execution controls, and read-only state inspection. Availability depends on permissions, GDB version, architecture, and executable and symbol formats. Verification against actual Windows targets remains outstanding; successful connection or complete information for every program is not guaranteed. Interpret a snapshot together with reproduction evidence and build conditions rather than treating one value as a conclusive diagnosis.
