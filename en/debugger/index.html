    Input and output
    Supports Linux ELF read, write and exit calls.
    

    First run
    Open ELF 64 and press F7 twice. RAX becomes 0 and RBX becomes 5. Click Continue to add 5 down to 1 and stop at HLT. RAX should now be 0xf.
    

    The result is also written to memory: look for 0f 00 00 00 at 0x100200 for ELF, 0x401100 for PE 32, or 0x140001100 for PE 64. These examples are CPU exercises for this browser.
    Supported scope
    Runs x86/x64 instructions and a few Linux input/output calls. Linux dynamic loaders, shared libraries and Windows DLLs and APIs are unavailable, so programs that need them may stop. Use local GDB mode to attach to processes or inspect source symbols.
    Runs up to 10,000 instructions at a time. Click Continue again when that limit is reached.
    Code edits and the stack
    To edit code, enter the instruction address and HEX bytes under Write memory. The new bytes take effect on the next execution. There is no assembly-text editor or patched executable download yet. Inspect the stack by entering the ESP or RSP value in the memory view. Browser mode does not have a dedicated call-stack panel.
    Saved sessions
    Wait for the saved indicator before closing. The save includes your file, execution position, memory, breakpoints and input/output. Clearing browser data, closing a private window or browser storage eviction can remove it. With multiple tabs open, the last save wins.
