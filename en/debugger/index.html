Input and output
Supports a limited read, write and exit syscall interface for Linux ELF.


First run
Open ELF 64 and press F7 twice: RAX is 0 and RBX is 5. The loop adds 5 down to 1. Continue and check that RAX becomes 0xf. The bytes 0f 00 00 00 are also written at 0x100200 for ELF, 0x401100 for PE 32, and 0x140001100 for PE 64. These are browser CPU exercises that stop at HLT.


Supported scope
Maps x86/x64 ELF and PE images and executes their machine code with Unicorn. This mode does not run a complete operating system. Linux dynamic loaders and shared libraries, and Windows DLLs and APIs, are not provided. Execution stops when it needs an unavailable operation or memory region. Use local GDB mode for attaching to processes and source-symbol debugging.
Runs up to 10,000 instructions per request. Continue again after reaching the execution budget. Memory and input/output stay in this tab and are cleared on reload.
