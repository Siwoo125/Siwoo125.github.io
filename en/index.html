DBG Desk

DBG Desk runs x86/x64 machine code in your browser. Choose an ELF or PE file to inspect instructions, registers and memory, with no Python installation or local engine connection. Selected files stay in this tab.

Step through one instruction at a time, continue to an address breakpoint, and edit registers or mapped memory while stopped. The included ELF and PE examples let you check the same calculation in both 32-bit and 64-bit mode.

Browser mode provides CPU emulation and a limited Linux input/output interface. Linux dynamic loaders and shared libraries, and Windows DLLs and APIs, are not included. It stops with an explanation when a required operation is unavailable. Use advanced local GDB mode for native operating-system behavior, process attachment, symbols and the existing investigation tools.

Twenty-one Korean and English guide topics explain breakpoints, stepping, memory errors and reproducible investigations. The verified CTF lab uses local GDB. The public website and browser mode do not upload your binary or debugging state.

Local GDB setup and source download

For native debugging, install Python 3.10 or later and GDB. On Windows, install GDB with MSYS2 UCRT64:

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

Extract the ZIP and double-click start-windows.bat. On Linux, run sh start-linux.sh.
