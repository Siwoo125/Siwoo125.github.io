DBG Desk

A browser interface for GDB running on your computer.

Open a binary, set breakpoints and inspect registers, instructions, memory and the call stack. Search loaded memory with HEX patterns or UTF-8 text, inspect numeric values, compare two recorded stops and export a Markdown report. This public website provides guides and the source download; start the Python server on your PC to use the debugger.

Open debugger

Run locally

Install Python 3.10 or later and GDB. On Windows, install GDB and GCC with MSYS2 UCRT64:

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

Extract the source ZIP, then run this command in its folder:

py -3 server.py --gdb C:\msys64\ucrt64\bin\gdb.exe

Open the local URL printed in the terminal. Select or drop a file to load it; execution starts only when you press Run.

Breakpoints and context

Use comparison conditions, ignored hit counts and temporary breakpoints to narrow down stops. Data breakpoints can stop on memory changes or accesses. Select a thread or stack frame to inspect its registers and local variables. Source-line stepping and run to address complement instruction stepping.

Testing and limitations

Native GDB debugging of a C example was verified on a GitHub Windows runner with MSYS2 UCRT64. This does not guarantee compatibility with every binary. GDB is installed separately. LLDB, WinDbg, disk file patching and reverse execution are not included. CTF tools support memory/register edits, ELF/PE headers, strings and first-instruction stops. Linux target input uses a PTY; Windows uses a separate console. The download contains source code and setup instructions, not a bundled GDB installation.
