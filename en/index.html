DBG Desk

A browser interface for GDB running on your computer.

Open a binary, set breakpoints and inspect registers, instructions, memory and the call stack. Compare two recorded stops and export a Markdown report. This public website provides guides and the source download; start the Python server on your PC to use the debugger.

Run locally

Install Python 3.10 or later and GDB. On Windows, install GDB and GCC with MSYS2 UCRT64:

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

Extract the source ZIP, then run this command in its folder:

py -3 server.py --gdb C:\msys64\ucrt64\bin\gdb.exe

Open the local URL printed in the terminal. Select or drop a file to load it; execution starts only when you press Run.

Testing and limitations

The native Windows debugging test has not yet been run in a Windows environment. GDB is installed separately. LLDB, WinDbg, memory editing and an interactive target terminal are not included. The download contains source code and setup instructions, not a bundled GDB installation.
