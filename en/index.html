DBG Desk

Open an ELF or PE file and step through its x86/x64 instructions in your browser. Registers and memory sit next to the code. There is nothing to install, and your file is not uploaded.

Set a breakpoint by clicking an address, or edit a register or memory value while stopped. Not sure where to start? Open an ELF or PE example and follow the loop that adds 5 down to 1.

With auto-save on, this browser keeps your latest file, execution position, memory, breakpoints and input/output in this browser. Wait for the saved indicator before closing. Reload the page to pick up where you left off.

Browser mode emulates the CPU and a few Linux input/output calls. It cannot load Linux shared libraries or Windows DLLs and APIs. Use local GDB mode when your program needs those, or when you need to attach to a process or inspect source symbols. The guides cover setup, breakpoints, memory errors and CTF exercises.

Local GDB setup and source download

For native debugging, install Python 3.10 or later and GDB. On Windows, install GDB with MSYS2 UCRT64:

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

Extract the ZIP and double-click start-windows.bat. On Linux, run sh start-linux.sh.
