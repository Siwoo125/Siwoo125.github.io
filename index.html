DBG Desk

DBG Desk는 브라우저 안에서 x86/x64 기계어를 실행하는 디버거입니다. ELF나 PE 파일을 선택하면 명령어, 레지스터와 메모리를 확인할 수 있습니다. Python 설치나 로컬 엔진 연결 없이 시작하며 선택한 파일은 이 탭 안에서 처리합니다.

명령어를 하나씩 실행하거나 주소 중단점까지 진행하고, 정지 상태에서 레지스터와 매핑된 메모리를 수정합니다. 포함된 ELF·PE 예제로 같은 계산을 32비트와 64비트에서 각각 따라갈 수 있습니다.

브라우저 모드는 CPU 실행과 제한된 Linux 입력·출력을 제공합니다. Linux 동적 로더·공유 라이브러리와 Windows DLL·API는 포함하지 않습니다. 지원하지 않는 동작이 필요하면 이유를 표시하고 멈춥니다. 운영체제의 실제 동작, 프로세스 Attach, 심볼과 기존 조사 도구가 필요하면 고급 로컬 GDB 모드를 사용하세요.

한국어·영어 21개 주제의 가이드에서 중단점과 단계 실행, 메모리 오류와 재현 방법을 다룹니다. 검증된 CTF 실습은 로컬 GDB 기준입니다. 공개 사이트와 브라우저 모드는 바이너리와 디버깅 상태를 서버로 업로드하지 않습니다.

로컬 GDB 설치 안내와 소스 다운로드

운영체제의 실제 프로그램을 디버깅하려면 Python 3.10 이상과 GDB가 필요합니다. Windows에서는 MSYS2 UCRT64로 GDB를 준비합니다.

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

ZIP을 풀고 Windows에서는 start-windows.bat를 엽니다. Linux에서는 sh start-linux.sh로 실행합니다.
