DBG Desk

내 PC의 GDB를 브라우저에서 사용하는 디버거입니다.

바이너리를 열어 중단점을 걸고 명령어, 레지스터, 메모리와 호출 스택을 확인합니다. 메모리를 HEX·문자열로 검색하고 바이트를 정수·실수로 읽을 수 있습니다. 두 정지 시점의 값을 비교하고 Markdown 보고서로 저장할 수도 있습니다. 이 공개 사이트에서는 가이드와 소스를 제공합니다. 디버깅 화면은 내려받은 Python 서버를 PC에서 실행해 엽니다.

로컬에서 실행하기

Python 3.10 이상과 GDB가 필요합니다. Windows에서는 MSYS2 UCRT64 터미널에 다음 명령을 입력합니다.

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

소스 ZIP을 풀고 해당 폴더의 터미널에서 실행합니다.

py -3 server.py --gdb C:\msys64\ucrt64\bin\gdb.exe

터미널에 나온 로컬 주소를 엽니다. 파일 선택이나 드래그로 바이너리를 불러온 뒤 실행 버튼을 누릅니다.

소스 ZIP 다운로드 · SHA-256

검증 범위와 제한

Windows 실제 프로세스를 대상으로 한 검증은 아직 남아 있습니다. GDB는 별도로 설치해야 합니다. LLDB·WinDbg 연결, 메모리 수정, 대상 프로그램용 대화형 터미널은 제공하지 않습니다. 다운로드에는 소스와 설치 설명이 포함되며 GDB 자체는 들어 있지 않습니다.
