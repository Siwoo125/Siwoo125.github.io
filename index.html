ELF·PE 파일을 열고 x86/x64 명령어를 한 줄씩 실행해 보세요. 코드 옆에서 레지스터와 메모리가 어떻게 바뀌는지 볼 수 있습니다. 따로 설치할 프로그램은 없고, 파일을 서버로 보내지도 않습니다.

주소를 누르면 중단점이 생깁니다. 멈춘 상태에서 레지스터나 메모리 값을 바꿀 수도 있습니다. 처음이라면 ELF·PE 예제를 열어 보세요. 5부터 1까지 더하는 짧은 반복문으로 시작할 수 있습니다.

자동 저장을 켜 두면 마지막 작업이 이 브라우저에 남습니다. 저장됨 표시를 확인하고 닫으면 됩니다. 다시 열거나 새로고침해도 파일, 실행 위치, 메모리, 중단점과 입력·출력을 이어서 볼 수 있습니다.

브라우저 모드에서는 CPU와 일부 Linux 입력·출력만 실행합니다. Linux 공유 라이브러리나 Windows DLL·API가 필요한 프로그램은 로컬 GDB 모드를 쓰세요. 실행 중인 프로세스에 붙거나 소스 심볼을 볼 때도 GDB가 필요합니다. 설치 방법과 중단점, 메모리 오류, CTF 실습은 가이드에 정리했습니다.

로컬 GDB 설치 안내와 소스 다운로드

운영체제의 실제 프로그램을 디버깅하려면 Python 3.10 이상과 GDB가 필요합니다. Windows에서는 MSYS2 UCRT64로 GDB를 준비합니다.

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

ZIP을 풀고 Windows에서는 start-windows.bat를 엽니다. Linux에서는 sh start-linux.sh로 실행합니다.
