DBG Desk

내 PC의 GDB를 브라우저에서 사용하는 디버거입니다.

바이너리를 열어 중단점을 걸고 명령어, 레지스터, 메모리와 호출 스택을 확인합니다. 메모리를 HEX·문자열로 검색하고 바이트를 정수·실수로 읽을 수 있습니다. 두 정지 시점의 값을 비교하고 Markdown 보고서로 저장할 수도 있습니다. 이 공개 사이트에서는 가이드와 소스를 제공합니다. 디버깅 화면은 내려받은 Python 서버를 PC에서 실행해 엽니다.

디버거 열기

로컬에서 실행하기

Python 3.10 이상과 GDB가 필요합니다. Windows에서는 MSYS2 UCRT64 터미널에 다음 명령을 입력합니다.

pacman -S --needed mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-gcc

소스 ZIP을 풀고 해당 폴더의 터미널에서 실행합니다.

py -3 server.py --gdb C:\msys64\ucrt64\bin\gdb.exe

터미널에 나온 로컬 주소를 엽니다. 파일 선택이나 드래그로 바이너리를 불러온 뒤 실행 버튼을 누릅니다.

소스 ZIP 다운로드 · SHA-256

중단점과 조사 문맥

조건 비교식, 건너뛸 횟수와 임시 중단점으로 필요한 정지 지점을 고릅니다. 데이터 중단점은 메모리 값의 변경이나 접근을 감시합니다. 스레드·호출 프레임을 선택해 해당 문맥의 레지스터와 지역 변수를 확인하고, 소스 줄 실행이나 선택 주소까지 실행할 수 있습니다.

검증 범위와 제한

GitHub Windows 환경의 MSYS2 UCRT64에서 C 예제의 실제 GDB 실행·중단점·스레드·프레임·메모리 조회를 검증했습니다. 모든 실행 파일의 호환성을 보장하지는 않습니다. GDB는 별도로 설치해야 합니다. CTF 도구는 메모리·레지스터 수정, ELF/PE 헤더·문자열과 첫 명령어 정지를 지원합니다. Linux는 웹 입력 패널을, Windows는 별도 콘솔을 사용합니다. LLDB·WinDbg 연결, 디스크 파일 패치와 역실행은 제공하지 않습니다. 다운로드에는 소스와 설치 설명이 포함되며 GDB 자체는 들어 있지 않습니다.
