사용 메모
DBG Desk는 사용자 PC의 GDB에 연결해 실제 프로그램의 실행 상태를 보여줍니다. 실행 파일을 열거나 PID로 연결한 뒤 중단점에서 명령어, 레지스터, 메모리와 호출 스택을 함께 확인할 수 있습니다. 브라우저의 화면만으로 다른 프로세스에 접근하는 방식이 아니므로 Python 로컬 서버와 대상에 맞는 GDB가 필요합니다. 파일과 디버깅 상태는 외부 서버로 업로드하지 않습니다.
처음 사용하는 경우 작은 예제에서 main에 정지한 뒤 단계 실행을 시작해 보세요. F7은 명령어 하나를 실행하고, F8은 함수 호출을 넘겨 진행하며, F9는 다음 중단점까지 계속 실행합니다. 값이 틀어지는 함수를 찾았다면 입구와 반환 직전의 상태를 비교하면 조사 범위를 줄일 수 있습니다. 메모리 창의 값은 정지한 시점의 자료이며 객체의 유효성이나 오류 원인을 자동 판정한 결과가 아닙니다.
정지 상태의 메모리·레지스터 수정과 첫 명령어 시작을 지원합니다. Linux에서는 웹 입력 패널을, Windows에서는 별도 대상 콘솔을 사용합니다. 파일 패치와 역실행은 지원하지 않습니다. Python traceback이나 일반적인 JavaScript 예외는 해당 언어의 디버깅 도구를 사용하는 편이 적합합니다. 구체적인 조사 순서는 가이드에서 확인할 수 있습니다.
