    레지스터

    중단점

    메모리

    

    입력 · 출력
    Linux ELF의 read·write·exit 호출을 사용할 수 있습니다.
    

    처음 실행하기
    ELF 64를 열고 F7을 두 번 눌러 보세요. RAX는 0, RBX는 5가 됩니다. 계속 실행을 누르면 5부터 1까지 더한 뒤 HLT에서 멈춥니다. RAX의 값이 0xf이면 계산이 끝난 겁니다.
    

    결과는 메모리에도 남습니다. ELF는 0x100200, PE 32는 0x401100, PE 64는 0x140001100에서 0f 00 00 00을 확인하세요. 예제는 이 브라우저에서 실행하는 CPU 연습용입니다.
    지원 범위
    x86/x64 명령어와 일부 Linux 입력·출력을 실행합니다. Linux 동적 로더·공유 라이브러리와 Windows DLL·API는 없어서, 이를 사용하는 프로그램은 실행 중 멈출 수 있습니다. 프로세스 연결이나 소스 심볼이 필요하면 로컬 GDB 모드를 쓰세요.
    한 번에 최대 10,000개 명령을 실행합니다. 한도에 걸리면 계속 실행을 다시 누르면 됩니다.
    코드 수정과 스택
    코드 바이트를 바꾸려면 메모리 쓰기에 명령어 주소와 HEX 바이트를 넣으세요. 바뀐 코드는 다음 실행부터 적용됩니다. 어셈블리 문장을 직접 입력하는 편집기와 수정한 실행 파일 다운로드는 아직 없습니다. 스택은 메모리 조회에 ESP 또는 RSP 값을 넣어 볼 수 있습니다. 브라우저 모드에는 호출 스택 전용 창이 없습니다.
    저장한 작업
    저장됨 표시를 확인한 뒤 닫으세요. 파일, 실행 위치, 메모리, 중단점과 입력·출력이 함께 저장됩니다. 브라우저 데이터를 지우거나 비공개 창을 닫으면 저장본이 없어질 수 있습니다. 브라우저가 저장 공간을 정리할 때도 삭제될 수 있습니다. 여러 탭에서 쓰면 마지막에 저장한 작업이 남습니다.
