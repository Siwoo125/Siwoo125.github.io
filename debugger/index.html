브라우저 디버거

파일 없음
ELF·PE 파일을 선택하거나 여기에 놓으세요. 최대 32 MiB.

설치와 로컬 엔진 연결 없이 이 탭에서 실행합니다. 선택한 파일은 서버로 업로드하지 않습니다.

실행 예제

파일이나 실행 예제를 선택하면 진입점에서 정지합니다.

주소를 누르면 중단점을 추가합니다.

주소바이트명령어

레지스터

중단점

메모리



입력 · 출력
Linux ELF의 제한된 read·write·exit 시스템 호출을 처리합니다.


처음 실행하기
ELF 64 예제를 열고 F7을 두 번 누르면 RAX는 0, RBX는 5가 됩니다. 반복문은 5부터 1까지 더합니다. 계속 실행한 뒤 RAX가 0xf인지 확인하세요. ELF 예제의 0x100200, PE 32의 0x401100, PE 64의 0x140001100에도 0f 00 00 00이 기록됩니다. 이 예제는 브라우저 CPU 실습용이며 HLT에서 멈춥니다.


지원 범위
x86/x64 ELF와 PE를 메모리에 올리고 Unicorn으로 실제 기계어를 실행합니다. 운영체제를 통째로 실행하는 모드는 아닙니다. Linux 동적 로더·공유 라이브러리와 Windows DLL·API는 제공하지 않습니다. 해당 기능이나 매핑되지 않은 메모리가 필요하면 정지합니다. 외부 프로세스 Attach와 소스 심볼 디버깅은 로컬 GDB 모드를 이용하세요.
한 번에 최대 10,000개 명령을 실행합니다. 실행 한도에 도달하면 계속 실행을 다시 누르세요. 메모리와 입력·출력은 이 탭의 메모리에만 보관하며 새로고침하면 사라집니다.
